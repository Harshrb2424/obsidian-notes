

## Live Instructional Session

The Plexus Design Team will lead a comprehensive walkthrough focusing on the structural pillars of Figma.

### Interactive Demo File

Participants should open the following community file to follow along with the live demonstration:

- [Figma for Education Basics - Demo File](https://www.figma.com/design/iKBLyvwNw9WnuyyAQx2Wm6/Figma-for-Edu-Basics--Community-?node-id=0-1&t=MNDXqg5urViwsOLL-1)
    

### Key Learning Modules

1. **Interface Navigation:** Introduction to the Toolbar, Layers Panel, Assets, and Properties Panel.
    
2. **Vector Essentials:** Creating and manipulating text, primitive shapes, and image masks.
    
3. **Spatial Logic:** Techniques for arranging, resizing, and scaling objects with precision.
    
4. **Design Systems:** Introduction to the concept of Layout Grids and reusable Components.
